# Трансляция экрана модератора: предложение

Функция пока не реализована. Рекомендуемый вариант — WebRTC: захват через
`getDisplayMedia`, обмен SDP/ICE через существующий Socket.IO, вывод MediaStream
в отдельном video-виджете OBS. Модератор каждый раз нажимает «Поделиться экраном»
и выбирает окно, вкладку или экран в системном диалоге браузера.

Нужны HTTPS (или localhost), явное согласие пользователя, кнопка остановки,
индикатор трансляции и освобождение tracks/peer connections при остановке,
закрытии вкладки и потере подключения. Звук зависит от браузера и выбранного
источника; его доступность нельзя обещать для любого окна.

Сервер должен разрешать отправку только авторизованному модератору с отдельным
правом, а получение — OBS с действующим overlay token того же стримера.
Сигналинг необходимо проверять и ограничивать по размеру и частоте.
Состояние экрана не сохраняется как постоянно работающий источник после рестарта.

HTTP-туннель может передавать сигналинг, но не заменяет TURN для WebRTC.
Прямое соединение может работать бесплатно; если NAT/фаервол его блокирует,
нужен доступный TURN-сервер. Поэтому гарантировать работу в любых сетях
полностью бесплатно нельзя. Первый этап — прототип между реальными ПК
модератора и стримера с проверкой в OBS. Не использовать передачу кадров
через Socket.IO как замену видео: это добавляет нагрузку и задержку.

- https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia
- https://webrtc.org/getting-started/turn-server
