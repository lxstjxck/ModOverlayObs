# Moderator Overlay для OBS

Веб-приложение для управления оверлеем OBS. Модератор размещает текст, изображения,
GIF, видео и аудио на полотне, а стример показывает результат через источник
«Браузер» в OBS. Центральная область полотна соответствует кадру 1920 × 1080.

## Возможности

- Загрузка медиа с компьютера, включая drag-and-drop, и добавление по ссылке.
- Медиатека с миниатюрами и список объектов на полотне.
- Перемещение, изменение размера, обрезка и настройка видимости объектов.
- Редактирование текста и его оформления.
- Воспроизведение файлов и YouTube, перемотка и раздельная громкость для модератора и OBS.
- Синхронизация изменений через Socket.IO и сохранение состояния в SQLite.
- Панель EMOTES для смайликов канала Twitch, активного набора 7TV и ссылок Custom.

Для внешних медиа нужны прямые ссылки на файлы или поддерживаемые ссылки YouTube.
Доступность воспроизведения зависит от источника и подключения компьютера с OBS.
Трансляция экрана пока не реализована.

## Технологии

React, TypeScript, Vite, Node.js, Express, Socket.IO, Prisma и SQLite.
Проект рассчитан на одного стримера и доверенную команду модераторов.

## Запуск

Требуется Node.js 22.12+ из ветки 22. Создайте `.env` на основе `.env.example`,
задайте собственный пароль владельца и случайный `SESSION_SECRET`.

```bash
npm ci
npm run db:push
npm run dev
```

Панель модератора: `http://localhost:5173/app`.
Настройка OBS и ссылка оверлея: `http://localhost:5173/obs-setup`.
Ссылку оверлея добавьте в источник «Браузер» OBS размером 1920 × 1080.

Для production настройте HTTPS-адрес и `NODE_ENV=production` в `.env`, затем:

```bash
npm run build
npm start
```

Также доступен запуск через `docker compose up -d --build` с подготовленным `.env`.

## Channel Emotes

В панели модератора откройте вкладку **EMOTES** и сохраните Twitch login канала. Создайте приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps), затем укажите его Client ID и Client Secret в серверном `.env` как `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`. Перезапустите сервер. Секрет не передаётся браузеру. Twitch Helix выдаёт channel emotes; 7TV определяется по Twitch ID канала и отдаёт его активный emote set. Если провайдер недоступен, другие разделы панели продолжают работать.

Если Twitch credentials пока нет, укажите числовой Twitch ID в необязательном поле панели: тогда 7TV работает без Twitch API. При наличии credentials ID определяется автоматически и сохраняется для следующих запросов.

Нажатие на смайлик добавляет обычный элемент **только в SPAWN**. После размещения используйте существующие действия Preview и Show Live. В CUSTOM можно сохранить страницу `https://7tv.app/emotes/<id>` или прямую публичную HTTPS ссылку на PNG, JPEG, GIF либо WebP. Удаление записи из CUSTOM сохраняет уже добавленные элементы на полотне. Анимированные GIF/WebP показываются обычным элементом изображения; для OBS рекомендуется проверить поддержку анимированного WebP в своей версии Browser Source.

Изображения Twitch и 7TV остаются на CDN и не занимают место в `uploads/` или upload quota. Для прямых Custom URL сервер не загружает и не проверяет файл: источник должен отдавать изображение по HTTPS и разрешать его загрузку браузером. CSP разрешает HTTPS изображения, включая произвольные Custom hosts; это существующее правило для внешних медиа. При неполадках проверьте login, Twitch credentials, доступность 7TV/CDN и консоль OBS Browser Source.

## Данные и безопасность

База хранится в `database/`, загруженные файлы — в `uploads/`.
Делайте резервные копии обеих папок. Не публикуйте `.env` и ссылку оверлея.
`INITIAL_ADMIN_PASSWORD` используется только при создании первого аккаунта
и не меняет пароль существующего пользователя.

Текущие ограничения и рекомендации описаны в [отчёте безопасности](docs/security-review.md).
