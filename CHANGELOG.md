# Changelog

## 2026-10-13

- Исправлена кнопка подключения нового собственного Twitch-канала при статусе `unconnected`.
- Один Twitch OAuth-вход с двумя разрешениями и единая сессия без роли канала.
- Список собственного и модерируемых каналов с переключением без повторного входа.
- Сервер определяет роль отдельно для каждого канала в HTTP API, Socket.IO, загрузках, OBS и TTS; при ошибке проверки Twitch доступ закрывается.
- Старые Twitch-сессии требуют повторной авторизации. Существующие записи OAuth и данные каналов сохраняются; миграция SQLite не нужна.
- Привязка Legacy-канала теперь завершает вход единой Twitch-сессией; парольный Legacy-вход остаётся доступным.
