# Changelog

## 0.1.7 — 2026-10-13

- Редактор: библиотека медиа показывает все файлы канала без поиска и фильтра; выбор одного, нескольких или всех файлов и массовое удаление используют существующее подтверждение и защищённый API. При частичной ошибке видны число удалённых и оставшихся файлов.
- Поле таймкода сохраняет ручной ввод во время воспроизведения, подтверждает перемотку по Enter и отменяет ввод по Escape или потере фокуса. В шапке редактора показан Twitch-логин вошедшего модератора; ссылка в кабинет приведена к текстовой навигации.
- Кабинет `/channels` разделён на вкладки «Стример» и «Модератор» с сохранением выбора в URL; `/streamer` открывает раздел стримера. Переключение использует текущую Twitch-сессию без повторного OAuth.
- Собственный канал и список модерируемых каналов показаны отдельно; владелец подключает только свой канал, а настройки OBS, команды, холста и TTS доступны только в его разделе при подтверждённом сервером доступе.
- Статусы подключения Browser Source названы «OBS подключён» и «OBS не подключён», переключатель и карточки адаптированы для мобильного экрана.
- Карточка LXST Overlay на главной ведёт авторизованного пользователя к каналам, гостя — на лендинг; до проверки сессии переход недоступен.
- Twitch-вход с публичной страницы открывается во всплывающем окне, использует существующую серверную сессию и проверяется повторно через API; при блокировке доступен обычный вход.
- Главная страница и лендинг Overlay показывают профиль, переход к каналам и выход для действующей Twitch-сессии.
- Обновлены общий геометрический знак LX и favicon; текстовый бренд остаётся LXST.
- Главная страница и лендинг Overlay используют единый футер с GitHub и контактной почтой.
- Карточка LXST Overlay целиком ведёт на страницу сервиса; LXST Chat остаётся недоступной до запуска.
- Введена шкала интерфейсных отступов и автоматическая проверка CSS, выровнены основные текстовые блоки.

## 2026-10-13

- Исправлена кнопка подключения нового собственного Twitch-канала при статусе `unconnected`.
- Один Twitch OAuth-вход с двумя разрешениями и единая сессия без роли канала.
- Список собственного и модерируемых каналов с переключением без повторного входа.
- Сервер определяет роль отдельно для каждого канала в HTTP API, Socket.IO, загрузках, OBS и TTS; при ошибке проверки Twitch доступ закрывается.
- Старые Twitch-сессии требуют повторной авторизации. Существующие записи OAuth и данные каналов сохраняются; миграция SQLite не нужна.
- Привязка Legacy-канала теперь завершает вход единой Twitch-сессией; парольный Legacy-вход остаётся доступным.
