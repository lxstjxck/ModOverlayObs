# Changelog

## 0.1.10 — 2026-10-15

- SEC-03: переименование медиа теперь требует серверного права `canDeleteMedia` для выбранного Twitch-канала; чтение медиа и схема SQLite не менялись.
- SEC-05: добавлены ограничения числа и размера элементов сцены, строгая схема `props`, атомарная проверка будущего состояния и режим удаления элементов старой слишком большой сцены без автоматической потери данных.
- SEC-04: Multer обновлён до 2.4.0; прерванные загрузки очищаются, а старые временные файлы Multer безопасно удаляются при запуске и периодически.
- Лендинг Overlay: убраны декоративные надзаголовки, устаревшие ссылки входа и информационный блок; `/login` перенаправляет на `/overlay`, ошибки OAuth показываются там же.
- Кабинет: карточки доступа модераторов, отдельное обновление только их списка, подтверждение смены OBS URL и подсказка о ручной перезагрузке источника.
- Смена OBS URL отзывает старый токен и соединения, сохраняя живую сцену; операция ограничена по частоте и доступна подтверждённому владельцу Twitch-канала.
- Владельцу подключённого канала доступна перезагрузка OBS Overlay с лендинга через существующий защищённый API; добавлены общий индикатор загрузки и анимация открытия страниц.

## 0.1.9 — 2026-10-14

- Главная страница: у заголовка естественный межбуквенный интервал, слово «стрима» стало белым и без точки; заголовок и описание выровнены по левому краю, надпись «СЕРВИСЫ» убрана.
- Кабинет каналов: удалены ручные поля размера Browser Source и проверка совпадения с холстом; добавлена короткая инструкция по настройке размера непосредственно в OBS.
- Главная страница: убрана ссылка «Сервисы» из шапки; кнопка в hero продолжает переходить к разделу.
- Кабинет каналов: Twitch-профиль перенесён в шапку рядом с выходом, а на узком экране имя и логин сокращаются без перекрытия кнопки.
- Редактор: выделение текста мышью отключено только в интерактивной области холста; поля свойств и OBS Canvas сохраняют прежнее поведение.

## 0.1.8 — 2026-10-14

- Главная страница: шапка встроена в поток страницы, навигация «Сервисы» доступна на узком экране, переход к разделу учитывает отступ и настройку уменьшения движения.
- Кабинет: убраны ссылки из шапки и повторяющиеся фиолетовые надзаголовки; кнопка перезагрузки OBS занимает ширину текста.
- В карточках модерируемых каналов показаны Twitch-аватары с буквенным резервным вариантом при отсутствии изображения или ошибке CDN.
- Ошибки получения профилей Twitch отмечаются безопасным сообщением в журнале; проверка доступа остаётся отдельной, а обновление повторяет пакетный запрос аватаров.
- Текущий знак LX загружается компонентом `BrandMark` из общего с favicon SVG-файла; будущий фирменный ассет можно заменить централизованно.
- Выровнены текстовые блоки главной страницы и лендинга Overlay; надпись `LXST ECOSYSTEM` удалена.

## 0.1.7 — 2026-10-13

- Редактор: библиотека медиа показывает все файлы канала без поиска и фильтра; выбор одного, нескольких или всех файлов и массовое удаление используют существующее подтверждение и защищённый API. При частичной ошибке видны число удалённых и оставшихся файлов.
- Поле таймкода сохраняет ручной ввод во время воспроизведения, подтверждает перемотку по Enter и отменяет ввод по Escape или потере фокуса. В шапке редактора показан Twitch-логин вошедшего модератора; ссылка в кабинет приведена к текстовой навигации.
- Кабинет `/channels` разделён на вкладки «Стример» и «Модератор» с сохранением выбора в URL; `/streamer` открывает раздел стримера. Переключение использует текущую Twitch-сессию без повторного OAuth.
- Собственный канал и список модерируемых каналов показаны отдельно; владелец подключает только свой канал, а настройки OBS, команды, холста и TTS доступны только в его разделе при подтверждённом сервером доступе.
- Статусы подключения Browser Source названы «OBS подключён» и «OBS не подключён», переключатель и карточки адаптированы для мобильного экрана.
- Карточка LXST Overlay на главной ведёт авторизованного пользователя к каналам, гостя — на лендинг; до проверки сессии переход недоступен.
- Twitch-вход с публичной страницы открывается во всплывающем окне, использует существующую серверную сессию и проверяется повторно через API; при блокировке доступен обычный вход.
- Главная страница и лендинг Overlay показывают профиль, переход к каналам и выход для действующей Twitch-сессии.
- Обновлены общий геометрический знак LX и favicon; текстовый бренд остаётся LXST.
- Главная страница и лендинг Overlay используют единый футер с GitHub и контактной почтой.
- Карточка LXST Overlay целиком ведёт на страницу сервиса; LXST Chat остаётся недоступной до запуска.
- Введена шкала интерфейсных отступов и автоматическая проверка CSS, выровнены основные текстовые блоки.

## 2026-10-13

- Исправлена кнопка подключения нового собственного Twitch-канала при статусе `unconnected`.
- Один Twitch OAuth-вход с двумя разрешениями и единая сессия без роли канала.
- Список собственного и модерируемых каналов с переключением без повторного входа.
- Сервер определяет роль отдельно для каждого канала в HTTP API, Socket.IO, загрузках, OBS и TTS; при ошибке проверки Twitch доступ закрывается.
- Старые Twitch-сессии требуют повторной авторизации. Существующие записи OAuth и данные каналов сохраняются; миграция SQLite не нужна.
- Привязка Legacy-канала теперь завершает вход единой Twitch-сессией; парольный Legacy-вход остаётся доступным.
